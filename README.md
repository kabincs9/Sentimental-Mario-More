A fun Python program that prints a **double Mario pyramid** (more comfortable version) of any height between 1 and 8.

## ✨ Overview

This program asks the user for a height and then prints two mirrored half-pyramids side by side with a gap in the middle — exactly like the "Mario More" problem from CS50.

It practices loops, validation, and clean output formatting in Python.

## 🎯 Features

- ✅ Prompts user for height (1 to 8 only)
- ✅ Robust input validation (re-prompts on invalid input)
- ✅ Prints a beautiful **double-sided Mario pyramid**
- ✅ Proper spacing and alignment
- ✅ Clean and readable code with good structure
